desglosados por superficie, torneo y año. Sin dependencias. Un solo archivo HTML.

---

## ✨ Interacción

- **Hover** sobre cualquier sección → la ilumina con glow propio de su superficie
- **Hover sobre un filtro** → preview visual instantáneo sin bloquearlo
- **Clic en un filtro** → aisla esa superficie o categoría (clic de nuevo para volver)
- **Tooltips inteligentes** → badges especiales para Grand Slams, Oro Olímpico y el Primer Título
